# Dokumentasi Proyek Aplikasi Audit QAS

Repositori ini memuat spesifikasi produk dan panduan implementasi aplikasi Audit Quality Assurance System (QAS) untuk logistik sepeda motor (Main Dealer & Depo Gudang: Karawang, Baros, Cirebon).

## Referensi Dokumen
- **PRD**: Dokumen Product Requirements Document lengkap di `qas_app_prd/PRD_Aplikasi_Audit_QAS_Cloudflare.docx` (dan script builder di `qas_app_prd/build_prd.py`).
- **Panduan Pembangunan**: Panduan teknis lengkap Cloudflare + Antigravity di `qas_app_guide/Panduan_Lengkap_Pembangunan_Aplikasi_Audit_QAS.docx` (dan script builder di `qas_app_guide/build_guide.py`).
